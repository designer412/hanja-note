나만의 한자장 - 무료 웹앱 시제품

포함 기능
- 손가락/마우스로 한자 쓰기 캔버스
- 한자, 음, 뜻, 메모 직접 등록
- 등록 한자 목록/검색/삭제
- 음과 뜻을 보고 손글씨로 답하는 복습 퀴즈
- 오답 우선 복습
- 브라우저 저장소에 데이터 저장

중요한 제한
현재 버전은 자동 손글씨 문자 인식(OCR)을 아직 포함하지 않습니다.
등록/퀴즈 화면에서 손으로 쓴 다음, 실제 한자는 입력 칸에도 직접 입력해 주세요.
정확한 자동 인식 기능은 별도의 한자 인식 엔진/API를 연결해야 합니다.

휴대폰에서 설치형 앱처럼 사용하기
1. 이 폴더를 정적 웹 호스팅에 올립니다(예: GitHub Pages).
2. 휴대폰 브라우저로 공개된 HTTPS 주소를 엽니다.
3. Android Chrome: 메뉴 > 앱 설치/홈 화면에 추가.
   iPhone Safari: 공유 > 홈 화면에 추가.
4. 앱 데이터는 해당 브라우저/기기에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.

index.html을 컴퓨터에서 직접 열어 기본 기능을 테스트할 수 있습니다.
서비스 워커를 통한 오프라인 캐시는 HTTPS 호스팅 환경에서 작동합니다.
